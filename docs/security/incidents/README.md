# Incidents

One file per incident or yearly dry run, named `YYYY-MM-DD-short-title.md`, written within 14 days of the fix (see [SECURITY.md](../../../SECURITY.md#incident-response)).

Each file covers: timeline (detection, confirmation, advisory, fix, release), cause, impact on users and their data, what users had to do, and what changes so it does not happen again. Dry runs say so in their title.
